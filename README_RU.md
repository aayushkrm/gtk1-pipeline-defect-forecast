# GTK1: триаж отчётов диагностики магистральных газопроводов

[Read in English](README.md)

Приватный R&D-репозиторий. Статус: скоуп заморожен, ждём данные партнёра. Сырые данные ВТД
в репозиторий не коммитятся.

## Что это

Таблицы аномалий прошлых диагностик (ВТД) превращаются в ранжирование 100-метровых участков
по P(вновь зарегистрированный дефект глубиной ≥ 10%). Ранжирование помогает планировать
шурфовки и обследования. Инструмент предсказывает отчётность, а не физическую коррозию.
Заявление о достоверности ≥ 80% на текущих данных необоснованно. Позиция подтверждена
доказательствами, а не оговорена.

## Что сделано

Разобраны 6 участков × 2–3 съёмки (2015–2025): таблицы аномалий плюс журналы швов и труб.
Описана схема 44/45 колонок, измерен дрейф порогов (у ПК2 counts: 164 → 9 → 55 на км),
восстановлены 5 повреждённых файлов. Построены метки matched-new (та же труба, ±2 м, ±0,5 м
по смещению, ±1 ч по ориентации) на сетке 100 м с нормализацией «глубина ≥ 10%».

Проведены эксперименты E01–E14, везде с бейзлайнами. Ранжирование B1 (персистентность прошлой
плотности) бьёт базовый уровень на 4 из 6 изученных участков, везде нижняя граница lift-CI
выше нуля. Два остальных не дают валидной пары: у ПК2 схема 2015 года на 23 колонки против 44
позже при доле ≥10% 6% против 96% (разные инструменты, а не рост); у Ю-Н ноль читаемых съёмок
аномалий (обе повреждены, запрошен реэкспорт). Детали: docs/DATA.md и scoping-записи в PROGRESS.md.

| Участок | Пара | B1 AP / base |
|---|---|---|
| Омск–Новосибирск 392–526 | 2016→2021 / 2021→2025 | 0,644 / 0,268 (triple 0,546 / 0,364 на ≥12 / ≥15%) |
| Парабель–Кузбасс-1 572–714 | 2022→2025 | 0,779 / 0,574 / 0,375 (562 позитива, стабильная методика) |
| СРТО–Омск 1608–1717 | 2016→2021 / 2021→2024 | 0,530 / 0,277 (тест, 63 позитива) |
| СРТО–Омск 1717–1759 | 2016→2021 | 0,181 / 0,031 (13 позитивов) |

Проверено и отправлено в карантин то, что не подтвердилось: HGB на уровне персистентности,
лог-линейная модель лучшая на counts (MAE 6,5 против 11,3), оверлей LR-nlag даёт +0,032 только
на ОН и ноль на других участках (архивирован, выключен). Вторая пара 1717 на восстановленной
копии показала 4,8-кратный методический скачок, поэтому она вне зачёта (правила R1–R4
в docs/GUARDRAILS.md). Работу гейтили 12 раундов ревью. Методы подкреплены 24 треками research.

Поставлено: 3 ретроспективные triage-страницы (ОН, ПК1, СРТО-1608) с heatmap, аудит-таблицами
и дисклеймерами; prospective-harness с регрессией IDENTICAL плюс форвардные вотчлисты;
пакет `src/gtk1/` с побайтовыми доказательствами миграции; зелёный test runner; runbook партнёра.

## Как организованы данные

Сырые файлы лежат вне репозитория в `../Данные для предварительного изучения/`: папка на участок,
внутри папки на годы съёмок. Каждая съёмка: файл аномалий плюс журнал швов или труб. Форматы
разные (`.xls`, `.xlsx`, `.csv`; десятичные через запятую в таблицах 2015 года; шапка mostly R4,
в новых файлах R1/R2). Координат нет нигде, поэтому джойны идут по номеру трубы плюс одометр.
Сырьё в git не попадает (проверяет hygiene gate в `run_tests.sh`).

## Как данные используются

```
load (толерантный .xls/.xlsx ридер) → normalize (глубина ≥ 10%, флаг corr, ключи труб)
→ match прошлое↔будущее по трубам → метки matched-new на 100 м
→ ранжирование B1 → вотчлист + heatmap + аудит-колонки
```

Воспроизвести:

```bash
pip install -r requirements.txt
bash run_tests.sh
python3 triage/prospective.py --section on --survey 2021 --check
python3 triage/prospective.py --section pk1 --survey 2025 --drop-last
```

## Карта

`src/gtk1/` (io, match, features, metrics) · `src/research_tools/` (клиенты Exa/Firecrawl/
Parallel/TinyFish + quad fan-out) · `src/tests/` · `experiments/` (E01–E14 frozen) ·
`triage/` (страницы, harness, вотчлисты) · `configs/` · `docs/` (PROBLEM, DATA, VALIDATION,
GUARDRAILS, TRIAGE_SPEC, RUNBOOK, OVERLAY_STATUS, research) · `outputs/` (игнорируемые CSV).

Правила: признаки только из прошлого, никакого тюнинга на тесте, негативы в отчёт,
один коммиттер. Детали: PROGRESS.md (append-only лог) и AGENTS.md (закон стиля проекта).
